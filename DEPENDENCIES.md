# Dependencies

## Unity ARKit Plugin

`TouchManager.cs` references `UnityEngine.XR.iOS` and
`UnityARHitTestExample`, which come from Unity's ARKit Plugin. This
plugin is not included in this repository -- it must be imported into
the Unity project separately before the `.unity` scenes will compile
and run.

## Unity scenes and scripts

No specific Unity Editor version is recorded. The `.unity` scene files
and `.cs` scripts were written in 2017 and target the Unity/ARKit
tooling available at that time.
